## 九、常见坑（Pitfalls）

1. **只生成了 config.yaml 却没配模型** → 启动后 UI 打不开或对话报错 "no model configured"。✅ 必须取消注释至少一条 `models:` 并配 `.env` 密钥。
2. **Windows 用 PowerShell 跑 `make dev`** → 失败。✅ 本地开发必须 Git Bash；Docker 路径无所谓（它内部用 Git Bash 包装）。
3. **Docker 没开机** → `make docker-start` 报 daemon 不可达。✅ 先确认 Docker Desktop 在运行。
4. **沙箱镜像拉不下来** → 不影响本地沙箱启动，可忽略；若要用 Docker 沙箱才需解决网络。
5. **改了 `.env` 以为要重启** → 其实模型元数据热更新，但**数据库驱动切换（postgres）** 需重装依赖/重启。
6. **端口 2026 被占用** → 改 `PORT` 环境变量或先停掉占用进程。
7. **误以为要自建 Postgres/Redis/MinIO** → 入门用默认 `sqlite` 即可，文档里那些是基础服务层的"可选"组件，不是启动门槛。
